# Web Development Quiz

A modern and interactive quiz website designed to test and improve your knowledge of **HTML, CSS, and JavaScript**. The project provides a simple and clean interface where users can select a category and answer a series of questions.

## ✨ Features

- 📚 **Three quiz categories:** HTML, CSS, and JavaScript.
- 🎯 **Interactive multiple-choice questions.**
- 📊 **Displays quiz results** with your final score.
- 🔄 **Option to restart the quiz** and try again.
- 🎨 **Clean and modern user interface.**
- 📱 **Responsive design** for different screen sizes (Mobile & Desktop).
- ⚡ **Fast and lightweight.**
- 🖱️ **Interactive buttons** and instant user feedback.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

## 🎮 How It Works

1. Open the quiz website.
2. Select a category: **HTML, CSS, or JavaScript**.
3. Answer the multiple-choice questions.
4. Receive your **final score** at the end.
5. Click **Restart** to try again!
